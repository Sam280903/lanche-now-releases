# LancheNow Desktop — versões

Este repositório guarda apenas os **instaladores** do LancheNow Desktop (programa de janela do LancheNow para Windows: painel, WhatsApp Web e robô de atendimento). Não contém o código-fonte do sistema.

## Baixar

Vá em [**Releases**](../../releases/latest) e baixe o arquivo `LancheNow-Setup-<versão>.exe`.

- Dois cliques instalam o programa só para o seu usuário (não pede administrador).
- O Windows pode mostrar "O Windows protegeu o computador": clique em **Mais informações › Executar assim mesmo**. O instalador ainda não tem assinatura digital.
- O programa só funciona com uma loja do LancheNow conectada (código de pareamento gerado no painel da loja).
- Depois de instalado, ele se atualiza sozinho a partir daqui.
